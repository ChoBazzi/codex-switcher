# ADR 0036: 신규 세션 잔여량과 등록 진단 분리

- 상태: accepted
- 날짜: 2026-09-08
- 관련: ADR 0016, 0033

일반 신규 세션은 최신 정상 사용량과 유효한 인증이 있고 두 구간 최소 잔여량이 양수이면 허용한다. 잔여량이 가장 큰 계정을 선택하고 동률이면 a를 선택한다. ADR 0016의 신규 세션 90% 사용 차단 규칙을 대체한다. 50%/10% 체크포인트 트리거의 자동 구현을 뜻하지 않는다. 명시적 인계 대상의 기존 여유량 검증은 이번 변경에서 유지한다.

등록 콜백 실패 시 cli_run_finished에 session_registration_code를 추가한다. 사용량 확인 불가, 로컬 인증 확인 실패, 배정 가능한 계정 없음, affinity 저장 오류, 기록 등록 오류, 바인딩 오류를 고정 코드로 구분한다. 복합 계정 문제에서는 인증 실패, 사용량 확인 불가 순서로 대표 원인을 보고한다. 원문 오류와 계정 식별자는 출력하지 않는다. 실패 요청 재전송과 자동 새 세션 생성은 없다.

Go 합성 검사로 10%/5%/0.1% 잔여 신규 등록과 0% 차단, 원인 코드 및 비밀정보 비출력을 검증한다. 앱의 기존 수동 인계 합성 검사는 Wiki 작성, 명시적 확인, 빈 입력 차단, 새 입력, 취소, 실패 재확인, 재시작 시 무호출을 검증한다. 실계정 앱 조작 검증은 사용자가 별도로 수행한다.
