# ADR 0035: 앱 계정 연결과 재로그인

- 상태: accepted
- 날짜: 2026-09-08
- 관련: ADR 0013, 0015, 0034

## 결정

후속 [ADR 0047](0047-five-account-capacity.md)이 최대 5개·단일 계정 추가 버튼·로그아웃 후 빈자리 재사용을 정의한다. 현재 UI에서는 미등록 고정 카드 대신 계정 추가를 사용한다.

미등록(`not_registered`) 계정 카드에서 `계정 연결 · 브라우저 로그인`으로 기존 helper `account login a|b`를 실행한다. `auth_expired`/`auth_error`는 기존 슬롯 재인증 `account reauth a|b`를 제공한다. 사용량 조회 실패/초기 미확인을 미등록으로 추정하지 않는다. auth_error는 Keychain 접근 실패 또는 서버 인증 오류일 수 있으며 등록 해제로 표시하지 않는다.

로그인은 명시적 버튼으로만 시작하며 모델을 호출하지 않는다. 기존 CLI가 브라우저 OAuth를 수행하고 Keychain에 저장한다. 앱은 토큰/인증 URL/실제 계정 ID를 읽거나 저장하지 않는다. 두 계정의 로그인은 하나씩 처리하고 앱 사용량 polling과 전환 시작을 로그인 중 보류한다. 종료 후 성공/실패/취소 모두 사용량을 한 번 갱신하여 실제 상태를 확인한다.

진행은 helper의 슬롯 일치 account_login 이벤트만 사용한다. 성공 이벤트와 프로세스 정상 종료를 함께 확인하며, 에러는 알려진 코드의 고정 문구만 표시한다. 원문 출력은 버리고 총 64 KiB/행 4 KiB 상한을 적용한다. 기존 Go 로그인 제한 5분과 별도로 앱은 305초 뒤 취소 신호, 취소 후 5초에도 실행 중이면 해당 프로세스를 강제 종료한다. 자동 재시도는 없다. 취소 직전 저장된 인증 정보는 삭제하지 않고 완료 후 조회로 확인한다.

재빌드 자체는 계정을 삭제하지 않는다. Keychain 서비스 키는 고정되어 있고, 코드 서명 변경에 따른 접근 승인 또는 토큰 만료는 별개다. 실제 사용자 환경에서 원인을 확인하기 전 로그인 데이터가 삭제됐다고 단정하지 않는다. Keychain 접근 오류에서 계정 저장소 초기화/자동 재등록은 하지 않는다.

## 검증

## 로그아웃

2026-09-10 수정: 메뉴바 창에서 확인 문구 표시 후 취소·확인 모두 입력되지 않는 사용자 보고가 있었다. 확인 전에는 helper를 호출하지 않으므로 백엔드 로그아웃 실행과 구분한다. OS 수준 원인은 직접 재현하지 못했으며, 중첩 `confirmationDialog`를 제거하고 같은 계정 카드 안에 확인·취소를 표시한다. 취소는 작업 중에도 가능하며 인증을 변경하지 않는다. 확인 시 현재 실행 가능 여부를 다시 검사하고 선택 슬롯을 먼저 소비하여 중복 제출을 막는다. 패널이 닫히면 확인 선택을 지운다. `ModelCheck`는 슬롯 보존·취소·busy 거절·단일 제출을 검사하며 실제 메뉴바 클릭은 수동 검증한다.

계정 카드의 로그아웃은 확인창 이후 `account logout a|b`를 한 번 실행한다. 선택 슬롯의 인증만 Keychain registry에서 제거하며 다른 슬롯은 유지한다. 브라우저/OpenAI 전체 세션의 원격 로그아웃은 아니고 Codex 전역 로그인도 변경하지 않는다. 상태 조회 오류를 성공으로 표시하지 않으며 완료 이벤트와 정상 종료를 확인한다.

같은 슬롯에 다른 계정을 등록했을 때 이전 continuation이 전송되지 않도록, 해당 슬롯의 affinity를 blocked로 전환하고 원본/대상이 해당 슬롯인 미사용 인계 예약을 제거한 후 인증을 제거한다. 실행 중 CLI가 affinity 잠금을 소유하면 로그아웃은 거절한다. 대화 및 Wiki 파일은 보존한다. DB와 Keychain은 단일 트랜잭션이 아니므로 Keychain 쓰기가 실패하면 인증은 남아 있을 수 있지만 기존 세션은 보수적으로 차단된 상태일 수 있다. 자동 되돌림/재시도는 하지 않는다.

합성 검증: 다른 슬롯 인증 보존, 미등록 반복 로그아웃, 잘못된 슬롯/저장소 오류 거절, 원본 재개 및 예약 차단, 다른 세션 보존, 앱 로그아웃 이벤트/종료 확인. 실제 사용자 계정을 개발 테스트에서 삭제하지 않는다.

`macos/Checks/AccountLoginCheck.swift`에서 합성 helper로 미등록/만료 명령 선택, 잘못된 슬롯 이벤트 거절, 원문 비노출, 중복 실행 방지, 정상 종료 검증, 중복 계정 오류, 취소를 검사한다. 전체 verify.sh에 포함한다. 실제 브라우저 인증/Keychain 승인과 재빌드 후 접근은 사용자 수동 검증 대상이다.
