# ADR 0031: 메뉴바 UI 첫 단계와 활성 세션 강조

- 상태: accepted (사용량 UI 및 합성 상태 미리보기)
- 날짜: 2026-09-07
- 관련: ADR 0001, 0007, 0015, 0030

후속 ADR 0032에서 실사용 세션 상태 연결, ADR 0033에서 명시적 Wiki 인계 제어를 추가했다. 아래 미연동 설명은 UI 첫 단계의 범위이며, 현재 세션 상태는 별도 읽기 전용 API로 제공하고 전환은 단발 helper 명령으로 실행한다.

## 결정

- macOS 13 이상 SwiftUI `MenuBarExtra` window 스타일로 시작한다. 외부 Swift 의존성 없이 Swift Package로 빌드한다.
- 활성 세션 카드 전체를 진한 파란색 배경과 흰색 글씨로 강조한다. 색상 외에도 `활성 세션` 문구를 표시한다. 선택·전환 준비·입력 대기를 활성 상태로 취급하지 않는다.
- 계정 A/B의 두 한도 구간을 동시에 표시한다. 잔여율, 서버 구간 길이 및 초기화 시각, 조회 상태와 마지막 성공 시각을 제공한다. 미확인은 0%가 아닌 —로 표시한다. 2분 초과 표본은 오래된 정보로 표시한다.
- 앱은 현재 활성 세션의 실시간 정보원이 없으므로 실사용 모드에서 `세션 연동 대기`를 표시한다. 사용량 성공을 CLI 연결 성공으로 해석하지 않는다. 전환 버튼은 미연동 표시와 함께 비활성화한다.
- `--demo`는 합성 데이터와 활성/준비/대기/실패 상태 선택기를 제공한다. 인증·네트워크·CLI 실행 및 전환은 하지 않는다.

## 임시 읽기 전용 연결

최종 통신은 ADR 0001의 독립 helper Control API/SSE를 유지한다. 이번 단계에서는 `--helper` 인수 또는 파일 선택으로 지정한 실행 파일을 `usage` 인수 하나로 호출하는 임시 어댑터를 사용한다. 쉘을 사용하지 않는다. 자동 PATH 탐색·로그인·모델 호출·인계는 하지 않는다.

즉시 조회 후 60초 주기 및 수동 갱신을 제공하고 중복 실행하지 않는다. 단발 프로세스 실패 시 즉시 재시도하지 않으며 다음 정규 조회만 수행한다. 표본 JSON이 유효하면 종료 코드 1의 계정별 오류도 반영한다. 이전 표본은 메모리에서 stale로 보존하되 미등록은 지운다. 출력은 128 KiB로 제한하고 30초 후 종료 신호, 32초 후 강제 종료한다. 원본 stderr는 UI나 로그에 표시하지 않는다. 계정 토큰과 인증은 Go helper만 접근한다.

실사용 모드의 앱 종료는 이 앱이 시작한 읽기 전용 단발 조회 외의 CLI/프록시 수명주기에 영향을 주지 않는다. 이 단계는 독립 상주 프록시를 시작하거나 중지하지 않는다. helper 경로는 아직 영속 저장하지 않는다.

## 검증 및 후속

- Swift 테스트: 사용량 파싱·범위·날짜 형식, 0/누락 구분, 2분 stale, 오류 시 보존/미등록 삭제, 실제 활성 단계만 강조.
- 수동: 데모에서 라이트·다크 모드의 가독성, 상태별 배경과 문구, 실제 helper 연결 시 A/B 사용량·새로고침·인증 오류를 확인한다.
- 후속: 세션 상태 Control API/SSE, Wiki 작성·재확인·예약 버튼 연결, 독립 helper 관리, 앱 번들/ad-hoc 서명. 이번 Swift Package 실행 파일은 배포용 앱 번들 완성이 아니다.
