# ADR 0056: 앱에서 Codex 설정 파일 직접 편집

- 상태: accepted (2026-09-12 사용자 요청으로 실행 옵션 폼 설계 대체)
- 날짜: 2026-09-12
- 관련: ADR 0038, 0055

## 배경과 결정

모델·권한 선택 폼 대신 config.toml과 AGENTS.md 원문을 편집하는 창을 제공한다. 앱에서 연결한 CODEX_HOME을 대상으로 하며 경로를 화면에 표시한다. 기본 ~/.codex나 프로젝트 파일을 암묵적으로 수정하지 않는다.

- 두 파일을 탭으로 전환하고 각각 초안을 유지한다. 현재 파일 저장만 디스크에 반영한다. 닫기 시 미저장 초안이 있으면 버리기를 확인한다.
- config.toml의 주석·미지의 키·순서를 포함해 원문을 그대로 편집한다. TOML 문법/모델 지원 여부 검사는 CLI가 수행하며 화면에 이를 명시한다. 프록시 연결 및 재시도 0 값 유지 안내를 표시한다.
- AGENTS.md는 해당 CLI 홈의 공통 지침이다. 파일이 없으면 빈 편집기를 표시하고 내용을 저장할 때 생성한다.
- UTF-8 일반 파일, 최대 1MB만 읽고 저장한다. 심볼릭 링크는 거절한다. 파일별 원본을 비교하여 외부 수정/삭제/생성을 발견하면 저장을 거절하고 초안을 보존한다. 원자 교체로 저장하고 권한 0600을 지정한다. 비교와 교체 사이의 극히 짧은 외부 쓰기 경쟁까지 잠그지는 않는다.
- 본문은 로그, 저장소, UserDefaults에 기록하지 않는다. 추가 백업 사본을 만들지 않는다.
- 연결/재개 명령은 CODEX_HOME만 지정한다. 이전 폼의 UserDefaults 값이나 명령행 모델·sandbox·approval 옵션으로 파일 설정을 덮어쓰지 않는다. 이전 저장 데이터는 삭제하지 않지만 더 이상 사용하지 않는다.
- 저장은 모델 호출·계정 전환·프록시 재시작을 일으키지 않는다. 현재 CLI 작업 종료 후 재실행/재개하여 적용한다. ADR 0055의 복구 시 사용자 config 보존 계약은 유지한다.
- 새 의존성 없음. TOML 재직렬화 대신 원문 편집으로 기존 설정 구조를 보존한다.

## 검증

`sh macos/Checks/verify.sh`: 합성 임시 홈에서 원문 로드·저장, AGENTS.md 생성, 0600 권한, 외부 변경 거절과 초안 보존, 재로드, 심볼릭 링크 거절, 재개 명령 shell 인자 및 밝은/어두운 편집 창 렌더링을 검사한다.

수동 확인: 설정 창 열기 → 경로 확인 → 두 탭에 초안 입력 → 파일별 저장 → 닫기 취소/버리기 → 다시 열어 저장된 원문 확인 → 현재 CLI 종료 후 같은 홈에서 재개. 실사용 파일은 합성 검증에 사용하지 않는다.
