# ADR 0052: 계정 요금제 표시

- 상태: accepted (합성 검증; 실제 응답 호환성은 사용자 확인)
- 날짜: 2026-09-11

기존 사용량 응답의 선택 메타데이터 `plan_type`을 `usage.plan_type`으로 전달하고 계정 카드에 표시한다. 별도 API 호출, 토큰 디코딩이나 가격·이용 가능량 추정은 하지 않는다. free/go/plus/pro/team/business/enterprise/edu만 표시용 상수로 허용하며 다른 값·누락·잘못된 자료형은 요금제 미확인이다. 잘못된 요금제 메타데이터가 정상 사용량 파싱을 실패시키지 않는다.

무료는 명시적인 free 응답으로만 표시한다. 구간 정보가 null이어도 존재하는 요금제를 보존하지만 잔여량은 미확인으로 유지한다. 사용량 조회 실패 시 이전 요금제가 남으면 이전 조회 정보라고 표시하고, 인증 변경/로그아웃 시 기존 사용량 무효화와 함께 제거한다. 요금제는 라우팅 및 로그아웃 허용 조건으로 사용하지 않는다.

공식 App Server 문서는 planType을 서버가 제공하는 경우에만 포함한다고 안내한다: https://learn.chatgpt.com/docs/app-server . 기존 wham endpoint는 공개 API 계약이 아니므로 이 문서가 해당 endpoint의 스키마를 보증하지는 않는다. plan_type을 제공하지 않는 응답은 미확인으로 처리한다.

검증: TestPlanMetadata(알려진 요금제, 누락/잘못된 형식, 잔여량 무추정, 원문 비노출), ModelCheck(무료·유료·미확인 라벨과 로그아웃 독립성), 기존 화면 렌더/빌드 검사. Lazyweb 도구 부재로 디자인 리포트 없이 기존 카드 안에 텍스트만 추가한다.
