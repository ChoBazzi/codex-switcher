# ADR 0027: 읽기 전용 CLI의 명시적 Wiki 작성과 로컬 게시

- 상태: accepted (단계적 연결, 전환 기능은 미포함)
- 날짜: 2026-09-07
- 관련: ADR 0006, 0009, 0010, 0024, 0025

## 결정

`exec -C DIRECTORY --resume HANDLE --checkpoint`는 현재 계정의 정상 완료 대화를 명시적으로 재개하여 Wiki를 작성하도록 요청한다. 이는 사용자 요청에 따른 모델 호출이며 자동 요약·실패 재시도가 아니다. 별도 요약 모델이나 다음 계정은 호출하지 않는다. 프롬프트와 --checkpoint는 함께 받을 수 없다.

현재 CLI는 읽기 전용이므로 이번 어댑터에서는 Codex가 Markdown 내용을 생성하고 helper가 원자적 파일 게시를 맡는다. ADR 0006/0010의 Codex 직접 파일 쓰기를 이 경로에 한해 대체한다. 텍스트 생성은 기존 프록시를 경유하며 도구 사용을 요청하지 않는다. 임의 개발 도구 지원이나 작업 경계 검증을 의미하지 않는다.

helper는 원본 origin과 고유 checkpoint_id를 포함한 문서 틀을 제공한다. 응답은 최대 32 KiB로 메모리 수집하고 터미널 진단에 원문을 출력하지 않는다. 기존 CLI 보존 기록에는 응답이 남는다. 계정 비밀정보와 continuation ID를 요약 본문에 쓰지 않도록 지시하지만 의미적 비밀정보 탐지/정확성을 보장하지 않는다.

3분 타이머는 신뢰된 launcher의 dispatch hook으로 실제 첫 upstream 시도 직전에 시작한다. 계정 조회/CLI 시작 대기는 제외한다. 타임아웃은 CLI를 취소하고 재전송하지 않는다. 두 번째 모델 요청은 MarkSent 상태 검사로 차단한다. EOF·프록시 완료·CLI 정상 종료 후 로컬 형식 검증을 수행한다.

private CLI home의 임시 디렉터리에 받은 문서를 저장하고 기존 checkpoint validator로 요청 ID, origin, 필수 항목, 종료 마커와 deadline을 검사한다. 성공한 동일 바이트만 `<-C 경로>/.codex-switcher/<worktree>/<branch>/<session>/checkpoint.md`로 원자 교체한다. 실패한 생성/검증은 프로젝트 기존 Wiki를 교체하지 않는다. 게시 후 디렉터리 sync 실패는 결과 불확실한 게시 오류로 표시한다. 임시 디렉터리는 정상 종료 때 제거하며 강제 종료 잔류 정리는 후속 작업이다. `.codex-switcher/`는 gitignore에 추가한다. Git 하위 폴더를 -C로 지정하면 해당 폴더 기준으로 게시하므로 이 단계에서는 저장소 루트에서 실행한다.

`cli_run_finished`는 모델 실행 결과이며 Wiki 게시 성공은 별도의 `checkpoint_saved`로 확인한다. 저장 성공에도 switch_ready=false이다. 계정 전환·새 CLI 시작·전체 대화 전달은 수행하지 않는다. 정상 모델 실행 후 검증 실패와 모델 자체 실패를 구별한다.

## 범위와 후속 작업

후속 ADR 0028에서 전역 최근 3개 백업과 영속 후보/등록 정보, CLI 명시적 재확인을 연결했다. 아래는 이 ADR 최초 구현 시점의 범위다.

전역 최근 3개 스냅샷, 영속 작성 요청/명시적 재확인, 사용량 임계값 예약, 안전한 작업 경계 검사, 대상 계정 확인, 사용자 입력 후 새 세션 연결, 메뉴바 UI는 미연결이다. 현재 저장 결과를 인계 예약으로 소비하지 않는다. 이전 실패 기록은 해제하지 않는다. 새 의존성 없음.

## 검증

합성 Wiki의 ID 일치, 게시 바이트/권한, 실패 시 이전본 보존, 크기 제한, 미전달 요청과 symlink 경로 거절을 검사한다. 실제 계정 호출은 개발 테스트에서 실행하지 않는다. 기존 합성 CLI 재개와 프록시 단일 시도 회귀 테스트도 유지한다. 실계정의 문서 형식 준수는 사용자 검증이 필요하다.
