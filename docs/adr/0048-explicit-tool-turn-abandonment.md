# ADR 0048: 도구 대기 턴의 명시적 중단 확인

- 상태: accepted
- 날짜: 2026-09-10
- 관련: ADR 0043, 0045

## 원인과 결정

모델이 도구 호출을 반환하면 HTTP 요청은 끝나도 CLI의 도구 결과/최종 답변을 기다리는 turnPending이 유지된다. 그 사이 CLI에서 Esc로 취소하면 프록시로 취소 이벤트가 오지 않을 수 있다. 시간 경과를 중단 증거로 삼거나 자동 잠금 해제를 하지 않는다.

앱은 can_abandon_turn 상태에서 `CLI 중단 확인 · 전환 잠금 해제`를 제공한다. 사용자는 CLI 도구 실행이 중단되고 입력 대기로 돌아온 것을 확인해야 한다. 이는 로컬 프로세스를 종료시키거나 실제 도구 정지를 검증하는 기능이 아니다. managed 제어 파이프의 abandon_turn은 현재 슬롯과 revision이 일치하고 HTTP 요청/대기 요청이 없으며 정상 도구 대기 상태일 때만 수락한다. 진행 요청이 시작되면 revision/idle 검사로 오래된 버튼 입력을 거절한다.

수락 시 turnPending만 해제하고 failed를 설정한다. 모델 호출·이력 편집·도구 재실행은 없으며 자동 라우팅도 즉시 재개하지 않는다. 이후 ADR 0045의 다른 계정 수동 선택과 새 사용자 입력 절차를 사용한다. 이전 입력·자동 후속 요청은 계속 차단하며 미완료 도구 쌍/압축은 기존 검사로 거절한다. 필요하면 새 대화를 사용한다. 버튼만으로 원래 작업이 복구된다는 보장은 하지 않는다.

앱은 ACK 전에는 추가 제어를 차단하고 3초 결과 미확인 시 재전송하지 않는다. 구 helper가 capability 필드를 보내지 않으면 버튼을 표시하지 않는다.

## 검증

TestProbeAbandonGuards: HTTP 진행·대기 요청·stale revision·비도구 상태·실패 상태 거절.
TestProbeAbandonToolTurn: 합성 도구 응답 후 잠금, 일반 전환 거절, 명시적 해제, 중복 거절, B 선택, 이전 입력 무호출 거절, 새 입력만 B로 전달. Swift 합성 파이프는 버튼 capability·ACK·busy 해제 및 다른 계정 선택 가능 상태를 검사한다. 실제 CLI Esc/앱 버튼 검증은 별도로 수행한다.
